# 查找小助手（TestPaper Copilot）

一个给**软件测试论文**做的证据型阅读工具：

> 上传 PDF → 提问 / 翻译 / 看引用图谱 / 写论述 → 回答必须标出 **[文件名 第X页]**；找不到就说“没有足够证据”。

这是给你这种“**C 组、刚装好 Python、没写过项目、11 月 17 日截止**”的情况准备的**可交版本**。
它不保证拿奖，但保证你能在截止前交出一个**能跑、能录屏、能公网演示**的作品。

---

## 0. 先说清楚：它能做什么，不能做什么

**能做：**
- 上传多篇文字版 PDF，按页提取文字并保留页码
- **问答**：只根据原文回答，并标页码；找不到证据时拒答
- **引用校验**：回答生成后，程序逐条检查页码是否真的在这次检索到的原文里、这句话有没有原文词面支撑；不通过会标黄/标红，并可一键“只重写这几句”
- **语义去重**：按内容（而非文件名）识别同一论文的不同版本（v1 vs v7），提示保留哪版，并能生成两版差异摘要
- **arXiv 检索入库**：关键词或 ID 直接检索 arXiv、下载 PDF 入库；摘要里有 GitHub 链接会自动标出（复现性提示）
- **流式回答**：问答逐字输出，不用等整段生成完
- **检索方式可切换**：混合（BM25 + 词面覆盖）/ BM25 / 旧版覆盖，侧栏一键切换，方便做 A/B 对比
- **双栏阅读器**：左侧 PDF 原页渲染（版式/公式/表格原样），右侧按页译文，翻页联动；问答里的引用可一键定位过去
- **引用图谱（轻量版）**：从 References 列表抽取“论文 → 参考文献”关系
- **写论述**：基于原文生成 Related Work / 研究现状草稿，每句带页码
- 多篇论文简单对比（生成表格）
- 部署到公网，评委点链接就能用
- 一键导出问答记录（JSONL），配合 `eval/` 算引用通过率、拒答准确率

**不能做：**
- 扫描件 OCR（扫描版 PDF 读不出文字）
- 完整的跨库引用网络（当前只解析论文自己的 References 列表）
- 不保证生成内容 100% 正确，提交前要逐句核对
- 用户登录 / 付费 / 多用户

**记住：先交“能跑的版本”，不要先学 React、Next.js、Docker。**

## 1. 10 分钟跑起来（Windows）

### 第 1 步：解压

把整个文件夹解压到：

```text
D:\feima_mvp
```

路径尽量简单，不要放在很深的中文文件夹里。

> 推荐 Python **3.11 或 3.12**。在命令行输入 `py --version` 可以查看。
> 如果你装的是最新的 3.13/3.14，`install.bat` 报“找不到合适的版本”，
> 就去 python.org 装一个 Python 3.11，安装时勾选 **Add Python to PATH**，再重新双击 `install.bat`。

### 第 2 步：安装依赖

双击：

```text
install.bat
```

等 2–5 分钟。看到 `Done` 就好了。
如果报错，把黑窗口里的红字截图发我。

### 第 3 步：拿一个 DeepSeek API Key

1. 打开 https://platform.deepseek.com/
2. 注册 / 登录
3. 点“API keys” → “创建 API key”
4. 复制 `sk-` 开头的那串
5. 充值 10 元（测试够用很久）

**不要把 Key 发给别人，也不要提交到 GitHub。**

### 第 4 步：启动

双击：

```text
run.bat
```

浏览器会自动打开：

```text
http://localhost:8501
```

如果没有自动打开，手动复制这个地址到浏览器。

### 第 5 步：第一次使用

1. 左侧粘贴 API Key；
2. 上传 2–3 篇**文字版** PDF 论文；
3. 点“建立索引”；
4. 输入问题；
5. 点“提问”。

## 2. 第一次演示，问这 3 个问题

### 问题 1：证明它能回答，还能指出页码

```text
哪篇论文在 Defects4J 上报告了 mutation score？给出页码。
```

预期：回答里出现 `[文件名 第X页]`，下面还能展开“查看 AI 实际读到的原文”。

### 问题 2：证明它能对比多篇

左侧勾选“多论文对比模式”，然后问：

```text
对比这几篇论文的数据集、指标和主要结论，做一个表格。
```

预期：Markdown 表格，每个单元格带页码；没写的写“未报告”。

### 问题 3：证明它不会瞎编

```text
这篇论文的工业落地客户是谁？
```

预期：回答“当前资料中没有足够证据”，而不是编一个公司名。

**把这三个镜头录进视频，你的核心 Demo 就有了。**

### 问题 4：证明“页码不是模型随口写的”（国赛差异点）

问完问题后，**不要只展示回答**，继续往下滚，展示：

1. 绿色横幅：`引用校验通过：N/N 条引用都能在本次检索到的原文中定位`；
2. 展开“逐条校验明细”：每一句话 → 引用 → 状态 → 支撑度 → 原文证据句；
3. 点开“查看 AI 实际读到的原文”，对照证据句。

如果某条被标成 `页码未命中` 或 `待核对`，**这是更好的素材**：点“修复未通过的引用”，
让它只重写这几句，再展示校验变成通过。评委看到的是「系统知道自己可能错，并且会自己改」。

## 4. 怎么把代码传到 GitHub（不用命令行）

推荐装 **GitHub Desktop**：

1. 下载安装：https://desktop.github.com/
2. 登录 GitHub 账号；
3. `File` → `Add local repository` → 选择 `D:\feima_mvp`；
4. 如果提示“not a repository”，点 `create a repository`；
5. 左下角填 Summary：`feat: first runnable demo`；
6. 点 `Commit to main`；
7. 点 `Publish repository`；
8. **取消勾选 `Keep this code private`**，让仓库 Public。

以后每天：

1. 打开 GitHub Desktop；
2. 它会列出你改过的文件；
3. 写一句 Summary，比如 `fix: improve citation prompt`；
4. 点 `Commit to main`；
5. 点 `Push origin`。

**不要用网页“上传整个文件夹”一次传完**，那样没有开发过程，比赛会扣分。

## 5. 怎么部署到公网（Streamlit Cloud）

1. 打开 https://share.streamlit.io/
2. 用 GitHub 登录；
3. 点 `Create app`；
4. 选择你的仓库、分支 `main`、主文件 `app.py`；
5. 点 `Advanced settings` → `Secrets`，填：

```toml
DEEPSEEK_API_KEY = "sk-你的Key"
```

6. 点 `Deploy`；
7. 等 2–5 分钟，得到一个 `https://xxx.streamlit.app` 的链接；
8. 用手机 / 无痕模式打开，确认不用登录、不用填 Key 也能问。

> 如果打不开：先检查仓库是不是 Public、`app.py` 路径对不对、Secrets 有没有保存。
> 还不行就先把本地版本录进视频，公网链接继续修。

## 8. 常见报错

**`'python' 不是内部或外部命令`**

用 `py` 代替 `python`。`run.bat` 已经帮你判断了。

**pip 下载很慢**

在命令行运行：

```bat
py -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**`No module named fitz`**

双击 `install.bat`，或：

```bat
py -m pip install PyMuPDF
```

**API 401 / 402**

- 401：Key 复制错了；
- 402：余额不足，去 DeepSeek 充值。

**`StreamlitSecretNotFoundError`**

本地：把 `.streamlit/secrets.toml.example` 复制成 `.streamlit/secrets.toml`，填入 Key。
云端：在 Streamlit Cloud 的 Secrets 里填 `DEEPSEEK_API_KEY`。

**PDF 读不出文字**

这是扫描件。这个保命版不支持 OCR，换文字版 PDF。

**8501 端口被占用**

```bat
py -m streamlit run app.py --server.port 8502
```

## 10. 这个版本能拿奖吗？

**不能保证。**

它保证的是：你能完整交出一个“能跑、能演示、有出处”的作品。
在 C 组里，**完整 > 炫技**。很多作品功能很多，但演示打不开、答案瞎编，反而丢分。

想加分，按顺序加：

1. **30 问评测表 + 引用通过率 / 拒答准确率**（`eval/` 已经搭好，只差你填页码）
2. **引用校验演示**（已内置：绿条 / 逐条明细 / 一键修复）
3. 多论文对比表 + 导出 CSV
4. 引用图谱（20 篇论文的引用关系）
5. 扫描件 OCR

**先交保命版，再加分。**
